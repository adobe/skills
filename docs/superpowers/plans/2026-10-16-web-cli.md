# `web` CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the nine per-skill browser scripts in `plugins/web` with one `web` CLI that skills, other plugins and external agents call.

**Architecture:** commander program → command modules (pure logic) → one driver module that is the only code spawning `playwright-cli`. In-page bundles move unchanged under `src/bundles/` and are injected after page load through `driver.run`. Every command prints one JSON document on stdout and uses the shared exit-code/error contract.

**Tech Stack:** Node ≥ 22.12 ESM (`.mjs` + JSDoc), commander 15, esbuild (dev) for the committed single-file `dist/web.mjs`, `node:test`, playwright-cli ≥ 0.1.20 on PATH.

**Spec:** `docs/superpowers/specs/2026-10-16-web-cli-design.md`

## Global Constraints

- Node ≥ 22.12, `"type": "module"`, ESM only; absolute-from-package imports (no `../`), ≤100 lines/function.
- Only `src/driver/playwright-cli.mjs` may spawn `playwright-cli`; always with `-s=<session>` and `--json`.
- Exit codes: `0` ok · `1` failure · `2` usage/environment · `3` blocked. Error document: `{ "error": { "code", "message", "hint" } }`.
- stdout carries exactly one JSON document (or one text block with `--format text`); everything else goes to stderr.
- Files handed to playwright-cli live under `--output` (default `./.web/`); never `os.tmpdir()`. Temp files are removed in `finally`.
- Session names: user-given or `web-<4 hex>`; no shared `default`. `WEB_SESSION` env is the fallback for `--session`.
- `file:` URLs are blocked by playwright-cli; tests needing a real page serve it with `node:http` on `127.0.0.1`.
- Minimum playwright-cli version `0.1.20`; absence/too-old → `PLAYWRIGHT_CLI`, exit 2, hint `npm install -g @playwright/cli@latest`.
- Old scripts are deleted in the same task that ships their replacement. No shims.
- Commits: imperative, ≤72 chars, conventional prefix (`feat(web-cli): …`), one task per commit unless a step says otherwise.

## Review Focus

1. A `page *` run interrupted by Ctrl-C leaves no browser behind → test in Task 3 (`withEphemeralSession` closes on thrown error) and Task 4 smoke (`list` empty after run).
2. Two `web` processes in one cwd with no `--session` must never share or clobber a browser or an artifact → Task 3 (unique names, `<session>-` artifact prefix test).
3. A page that is up but returns a challenge page (Cloudflare/Akamai) must exit 3, not 0 with garbage → Task 2 (`classifyPage` tests on challenge title / short body / 403).
4. `--session X` given but X is closed or unknown → exit 2 `NO_SESSION` with the `web browser open` hint, on every browser-touching command → Task 3 (`requireOpenSession`).
5. Agent passes a flag that does not exist (`--headless`, `--out`) → exit 2 with help, never silently ignored → Task 1 (`unknown option` test).

**Interfaces:**
- Produces `errors.mjs`: `class CliError extends Error { constructor(code, message, { hint } = {}) }`, `EXIT = { OK: 0, FAILURE: 1, USAGE: 2, BLOCKED: 3 }`, `exitCodeFor(code)` mapping `BLOCKED→3`, `NO_SESSION|SESSION_EXISTS|USAGE|PLAYWRIGHT_CLI|UNSUPPORTED→2`, anything else `→1`.
- Produces `output.mjs`: `emit(result, { format, text, stdout = process.stdout })` — `format: 'json'` writes `JSON.stringify(result, null, 2) + '\n'`; `format: 'text'` writes `text ?? JSON.stringify(result, null, 2)`; `fail(err, { stdout, stderr }) → number` writes the error document and returns the exit code (non-CliError → code `INTERNAL`, exit 1, message from `err.message`).
- Produces `cli.mjs`: `createProgram({ driverFactory }) → Command` with global options `--session <name>` (default `process.env.WEB_SESSION`), `--format <json|text>` (default `json`), `--output <dir>` (default `./.web`), `--headed`, `--recipe <file>`; `showHelpAfterError()`, `showSuggestionAfterError()`, `exitOverride()`; `runCli(argv, deps) → Promise<number>` wraps `parseAsync`, routes `CommanderError` with `code === 'commander.unknownOption' | 'commander.missingArgument' | 'commander.excessArguments'` to `USAGE` (exit 2), `commander.helpDisplayed`/`commander.version` to exit 0.
- `bin/web.mjs`: `#!/usr/bin/env node`, `process.exitCode = await runCli(process.argv)`.

### Task 2: playwright-cli driver

**Files:**
- Create: `plugins/web/cli/src/driver/exec.mjs`, `plugins/web/cli/src/driver/playwright-cli.mjs`, `plugins/web/cli/src/driver/blocked.mjs`
- Move: `plugins/web/skills/browser-probe/scripts/browser-probe.js` functions `checkHealth`, `detectSignals`, `parseEvalOutput`, constants `ERROR_TITLE_PATTERN`, `MIN_BODY_LENGTH` → `blocked.mjs` (the rest of that file moves in Task 5)
- Test: `plugins/web/cli/src/driver/playwright-cli.test.mjs`, `plugins/web/cli/src/driver/blocked.test.mjs`

**Interfaces:**
- `exec.mjs`: `execPlaywrightCli(args, { timeoutMs = 60_000, cwd = process.cwd() }) → { stdout, stderr, status }` via `spawnSync('playwright-cli', [...args, '--json'])`. Injected into the driver so tests never spawn.
- `playwright-cli.mjs`: `createDriver({ exec = execPlaywrightCli, outputDir, debug = Boolean(process.env.WEB_DEBUG) })` returning:
  - `ensureAvailable()` → throws `CliError('PLAYWRIGHT_CLI')` if missing or `< 0.1.20` (compare `--version` output with `semver`-free numeric tuple compare).
  - `open({ session, url, headed, config, cdpPort, persistent, initScripts = [] }) → { session, url, headed, cdpPort }` — `config` is a playwright-cli `browser` config object (from a recipe or built by `probe`); the driver writes `<outputDir>/<session>-cli-config.json` with `config`, `initScript: initScripts`, and `launchOptions.args` extended with `--remote-debugging-port=<cdpPort>` when set, then passes `--config=`; throws `SESSION_EXISTS` if `list()` already has `session` open; removes the config file in `finally`.
  - `goto(session, url) → void`.
  - `attach({ session, cdpUrl }) → { session, attached: true }` via `attach --cdp=<url> --session=<name>`.
  - `list() → Array<{ name, status, headed, browserType, attached }>` from `list --json`.
  - `close(session)`, `closeAll()`.
  - `evaluate(session, expr) → any` — wraps `expr` as `(() => { return (${expr}); })()` only when it contains no `;`, otherwise `(() => { ${expr} })()`; result = `JSON.parse(JSON.parse(stdout).result)`, falling back to the raw string when not JSON.
  - `run(session, { code, file }) → any` — writes `<outputDir>/<session>-run-<n>.mjs` when `code` given, then `run-code --filename=`; same result parsing.
  - `inject(session, bundlePath) → void` — `run` with `async page => { await page.evaluate(SRC) }` where `SRC` is the bundle source (JSON-stringified).
  - `cdp(session, method, params = {}) → any` — `run` with `async page => { const s = await page.context().newCDPSession(page); return s.send(METHOD, PARAMS) }`.
  - `screenshot(session, { path, fullPage, selector }) → { path }` — `screenshot [selector] --filename=<path> [--full-page]`.
  - `pageHealth(session) → { title, bodyLength, status? }` for `blocked.mjs`.
  - Every call: when `stdout` parses to `{ isError: true, error }` → `CliError('PLAYWRIGHT_CLI', error)`, except `/not open, please run open first/` → `CliError('NO_SESSION', …, { hint: 'run: web browser open <url> --session <name>' })`; spawn status `null` → `CliError('TIMEOUT')`.
  - `debug` true → every argv echoed to stderr prefixed `playwright-cli `.
- `blocked.mjs`: `classifyPage({ title, bodyLength, status, networkLines }) → { blocked: boolean, signals: string[] }` using the moved `checkHealth`/`detectSignals`; `assertNotBlocked(health)` throws `CliError('BLOCKED', …, { hint: 'web probe <url>, then retry with --recipe <file>' })`.
