# Pipeline facts — what the DA → EDS pipeline rewrites on delivery

Read this chapter when a page renders one way in the local harness and another on the preview host: every row is a delivery-time rewrite. This table is the fact catalogue only — the authoring rule for each row lives where the third column points, and the lint id names the detector that runs before the `PUT`. § Local emulation lists which rows the harness now reproduces (`scripts/pipeline-mimic.mjs`) and which it still cannot.

## Fact table

|---|---|---|
| section-metadata `style`: comma → N classes; a space-separated value → ONE hyphen-joined class that matches no rule (`rt band-navy` → `.rt-band-navy`) | comma-separate the tokens | `foundation.md` § 3 (#120) · `D15 STYLE-SPACE` 🟡 |
| a sole link wrapped by emphasis in either order (`<a><strong>`, `<b>`/`<i>`, alone in a `<li>`) is hoisted to `<strong><a>` and buttonized | emit the link plain; restore a systematic weight in block CSS; log `bold_links_flattened` | `encode-contract.md` § Pipeline-sensitive shapes · `D6 SOLE-EMPH` 🟡 |
| U+00A0 is copied byte-for-byte; a trailing NBSP is trimmed at delivery | converters strip `[ \t\r\n]` only; `sanitise.js` writes `&nbsp;`; a trimmed trailing NBSP is a ledgered residual (D8) | `encode-contract.md` § Pipeline-sensitive shapes · none |

## Local emulation (`scripts/pipeline-mimic.mjs`)

`build-harness.mjs`, `render-harness.mjs` and `block-roundtrip.mjs` run every row above through `pipeline-mimic.mjs` BEFORE the client runtime mimic, so section tagging, Experience Workspace instrumentation and decode all face the delivered shape; each run prints one line — `pipeline emulation: section-metadata N, meta N, picture N, hoist N, whitespace N, table→block N, icon N, heading-br N, emph-picture N, strip N` — so a page that exercised no rule is visible at a glance. `--no-pipeline` gives the old authored-shape harness for an A/B; `--style-split first-only` flips D7 for a stack measured to keep only the first `style` token; `--no-<rule>` disables one rule. Pinned by `evals/lint/pipeline-mimic-fixture.mjs`: `scripts/fixtures/pipeline-probe{,.plain}.html` (one instance of every rule; the expected file is derived from this table, so rows marked *assumed* rest on it alone) and `scripts/fixtures/pipeline-recorded.plain.html` (a redacted preview recording with `/media_<hash>` sets and real dimensions — every rule is a no-op on it, and the comparison normaliser is exercised against it).

Still NOT emulated — deployed-URL only: `/media_<hash>` URLs, `<source>` sets and real image dimensions; the real `/nav`, `/footer` and per-page `nav:`/`footer:` chrome (the dev-server harness proxies the wrong chrome; `render-harness --fragments` serves them from `content/` once its harness origin lands); font swap; CLS (#101). The harness number stays provisional — only the published gate counts (A116), one reconcile round is budgeted (A61).
