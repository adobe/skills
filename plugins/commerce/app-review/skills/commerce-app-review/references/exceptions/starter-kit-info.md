# starter-kit-info action

## Default

`NICE` — the submission guidelines mention `starter-kit-info` as useful for deployment tracking during review.

## Exception conditions

The `starter-kit-info` action is a starter kit artifact. Apps that have correctly cleaned up starter kit artifacts will not have it — and that is the right approach.

## When the exception applies

Do not flag the absence of a `starter-kit-info` action. Omit this finding entirely.
