# Breadcrumbs on pages under /products

We want a breadcrumb trail on every page under `/products` on this site, for example Home / Products / Shoes / Trail Runner. Authors should not have to type the trail into each page.

Add breadcrumbs to the site. Put a local test page at `drafts/breadcrumbs-test.html` (served by `aem up` from `./content/` or the `drafts` folder as you see fit) that shows the result, and write a short `BREADCRUMBS.md` at the repo root saying how an author turns breadcrumbs on or off for a page or a section, and where the implementation came from.
