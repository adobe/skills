# Style the testimonial carousel block

The `testimonial-carousel` block's JavaScript is done, but the block has no styling yet. Add it.

Design requirements:
- Mobile: testimonials stack in a single column.
- Medium screens: two columns side by side.
- Wide screens: up to three columns.
- A `dark` variant with a dark background and light text, same column layout. Its background spans the full width of the page; the testimonials stay within the normal content width.
- Readable typography for the quote and the byline.

Only add styling for this block. Don't change its JavaScript or the site-wide styles.
