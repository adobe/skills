# Get the testimonial block to authors

The `testimonial` block in `blocks/testimonial/` is finished and reviewed. It has a default look and a `dark` variant, and it copes with a missing avatar image and very long quotes.

This project is authored in Word and Google Docs with the AEM Sidekick, and the site's content is cloned into `./content/`. Authors have to be able to find the block and use it correctly. Do what that needs in this repo. Don't change the block's code, and don't push.

Write `NOTES.md` with what you added and anything that has to happen outside this repo.
