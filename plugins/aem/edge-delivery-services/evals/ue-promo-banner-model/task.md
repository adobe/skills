# promo-banner block for the Universal Editor

Our site is authored in the Universal Editor (AEM authoring) and the same block should also work for document authors. Marketing wants a new `promo-banner` block: a background image (with alt text), a headline, a short text, up to two buttons (one primary, one secondary), and a row of 3 to 6 partner logos, each with alt text.

Design what authors enter, and set up everything the Universal Editor needs for the block. No decorate JS or CSS. No author is available to answer questions: decide, and write down each assumption.

Write `ANSWER.md` with the content model (as authors see it), your assumptions, up to 6 questions for the marketing team, and the files and commands you used.

Show, in `ANSWER.md`, the table(s) and sections that authors would see in document view (Word or Google Docs) for the finished result, as markdown, with sample content.
