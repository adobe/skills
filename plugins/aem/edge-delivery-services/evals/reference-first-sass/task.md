# Sass for block CSS in local development

Our designers want to write block styles in Sass (`.scss`) instead of plain CSS. Nobody on the team wants to build or maintain a custom toolchain for this if someone has already solved it for Edge Delivery Services projects.

Set up Sass for this repository so that editing a `.scss` file produces the `.css` file the block loads, while running locally. Convert the `cards` block's CSS to Sass as the working example.

Write a short `SASS-SETUP.md` at the repo root saying where the setup came from, what you changed, how to run it, and anything the team should check before relying on it.
