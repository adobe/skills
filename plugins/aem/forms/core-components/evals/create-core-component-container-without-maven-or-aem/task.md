## Output Specification

Create the `stepgroup` container component with the files and wiring it needs. Write `REPORT.md` at the repository root describing what you verified and what you could not.

Existing sibling components such as `textinput`, `radiogroup` and `panelcontainer` are present. Maven and network access may be unavailable; if a command cannot run, say so instead of claiming it passed. In this task Maven and AEM are not available.
