# Changelog

## 1.0.0 (2026-05-15)

- Initial release
- Report script on @adobe/rum-distiller: traffic and Core Web Vitals at p75 with sample counts, device classes, LCP elements, the busiest pages, and pages ranked by traffic and severity
- Comparison with a baseline period: the share of good values with a significance test, pages that got worse, device mix and new LCP elements
- Rules for reading sampled data
- Reference for @adobe/rum-distiller: series, facets, filters, aggregates, statistics and the traps of its API
- Causes by metric for Edge Delivery Services, and a report template
